# exel

Приложение включает скрипт `process_103.py` для преобразования Excel-файлов в формат 103, графический интерфейс `interface.py` и веб-интерфейс `web_interface.py` для удобного запуска обработки.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Использование командной строки

```bash
python process_103.py --input данные.xlsx --output 103_result.xlsx --inn 7409002190
```

Дополнительные параметры:

- `--template` — путь к шаблону `Таблица1.xlsx`, из которого будет взят ИНН (колонка `inni`).
- `--region` — название региона для колонки `oblo` (по умолчанию «Челябинская область»).

## Графический интерфейс

Для запуска графического интерфейса выполните:

```bash
python interface.py
```

В открывшемся окне выберите исходный Excel, при необходимости укажите шаблон и путь к выходному файлу, задайте ИНН и нажмите «Обработать».

## Веб-интерфейс

Для запуска веб-приложения используйте:

```bash
python web_interface.py
```

После запуска перейдите в браузере по адресу [http://localhost:5000](http://localhost:5000) и загрузите исходный Excel-файл. При необходимости добавьте шаблон `Таблица1.xlsx`, укажите ИНН и регион. После отправки формы результат автоматически скачивается в формате 103.
